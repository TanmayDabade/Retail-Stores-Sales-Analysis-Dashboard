# 📊 Retail Store Sales Analysis Dashboard

An interactive **Retail Store Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, orders, profit margins, products, customers, and regional trends.

The dashboard transforms raw retail data into meaningful business insights through interactive visualizations, KPIs, and filters.

---

## 🚀 Project Overview

This project focuses on analyzing retail store data to help understand overall business performance and identify important sales and profit trends.

The Power BI dashboard provides insights into:

- 💰 Total Sales
- 🛒 Total Orders
- 📈 Profit Margin
- 📦 Sales Performance by Category
- 🌍 Regional Sales Analysis
- 📊 Product and Customer Insights
- 📅 Sales Trends Over Time

---

## 🛠️ Tools & Technologies Used

- **Microsoft Power BI**
- **Microsoft Excel**
- **Power Query** – Data Cleaning and Transformation
- **DAX** – Calculated Measures and KPIs
- **Data Visualization**

---

## 📂 Dataset

The dataset contains retail store transaction data, including information such as:

- Order ID
- Order Date
- Customer Details
- Product Category
- Product Information
- Sales
- Quantity
- Profit
- Region

The data was cleaned and transformed before being used for analysis in Power BI.

---

## 📊 Key Performance Indicators

The dashboard includes the following KPIs:

| KPI | Description |
|-----|-------------|
| 💰 Total Sales | Overall revenue generated |
| 🛒 Total Orders | Total number of customer orders |
| 📈 Profit Margin | Percentage of profit generated from sales |

---

## 🔍 Key Insights

The dashboard helps answer important business questions such as:

- Which product categories generate the highest sales?
- Which regions contribute the most to revenue?
- How does sales performance change over time?
- Which products generate higher profits?
- What are the overall sales and order trends?
- How can business performance be improved using data-driven insights?
